docker-compose - для поднятия инфраструктуры (БД, keycloak, consul)
.env - переменные среды

Модули проекта:
commons - общие классы
accounts-app - взаимодействие со счетами, ведение users
blocker-app - проверка подозрительных операций
cash-app - Операции положить / снять виртуальные деньги со своего счета в разных валютах
exchange-app - для операций конвертации валют
exchgenerator-app - генератор курсов валют
front-ui - взаимодействие с пользователем (фронтенд / бэк для вызовов соответствующих сервисов)
notifications-app - уведомления
template-app - шаблон микросервиса (вспомогательный)
transfer-app - переводы
